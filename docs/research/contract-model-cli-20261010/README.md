# 공개 사례 판단 모델을 Gooo 명령에서 사용하기

SDK0.2.36의 학습된 `model-contract-v1.json`을 일반 개발 컴파일러의 입력 확인,
코드 구성, 네이티브 실행에 연결했습니다. 공개된 예제 네 개를 골라 각각 다섯 명령을
한 번씩 실행했습니다. 원래 196개 학습·평가 실험은 다시 실행하지 않았습니다.

두 경계값 목표와 두 분기별 덧셈·뺄셈 목표를 사용했습니다. 각 쌍은 본문과 설명이 같고
기대하는 결과가 다릅니다. 경계값 예제는 학습에 들어갔고, 대입 예제는 이전 고정 실험에서
확인한 사례입니다. 이 관측은 기존 예제가 실제 컴파일러 경로로 이어지는지 확인합니다.

## 결과

| 원래 예제 | 고정 순서 시도 | 모델 시도 | 고정 순서 구성 시간 | 모델 구성 시간 |
| --- | ---: | ---: | ---: | ---: |
| bound-k7-r0-w0-direct-g0 | 1 | 1 | 1.052ms | 4.179ms |
| bound-k7-r0-w0-direct-g1 | 3 | 1 | 0.830ms | 3.531ms |
| offset-k11-r1-w0-assignment-g0 | 3 | 2 | 1.741ms | 3.915ms |
| offset-k11-r1-w0-assignment-g1 | 1 | 1 | 1.650ms | 3.854ms |

모든 작성 사례를 첫 선택에서 만족한 예제는 고정 순서 2/4, 모델 3/4였습니다.
후보 시도는 8회에서 5회로 줄었습니다. 최종 소스 출력 사례는 두 방식 모두 32/32,
조건 사례는 각각 12/12였습니다. 별도 네이티브 구성 실행과 저장 재실행도 각각
32/32개 사례를 통과했습니다. 구성 명령에서 Go를 빌드하고, 저장 재실행에서는
그 실행 파일을 재사용했습니다.

모델 호출은 코드 구성 네 번과 네이티브 구성 네 번에서 총 8회였습니다.
사전 입력 확인과 저장 재실행에서는 0회였으며, 후보 실패 뒤에도 추가 호출은 없었습니다.
모델 판단 자체는 20.750~37.959µs, 네 값의 중앙값은 21.250µs였습니다.
위 구성 시간은 소스 연결·모델 파일 읽기·사례 검사·최종 출력을 포함합니다.
이번 예제에서는 파일을 생략하는 고정 순서가 더 빨랐습니다.

20개 명령을 수행한 전체 과정은 wall 5.47초, user 1.94초, system 1.49초,
최대 RSS 87,900,160바이트(83.83MiB)였습니다. 네이티브 Go 도구 실행도 포함합니다.
평균 약 0.63개 CPU 코어에 해당하며 PC 전체 이용률의 증가분은 측정하지 않았습니다.
작은 네 예제를 한 번씩 실행한 결과이므로 넓은 성능 분포를 뜻하지 않습니다.

## 남긴 증거

- 실행 전에 고정한 [프로토콜](protocol.txt)과 [Go 실행기](producer/main.go).
- 깨끗한 생산자 소스 `4d4accf51ff8227293365ca92e4f3ddf2a5e8c57`, Go1.27.2,
  실제 공개 의존성 `v0.2.36-experimental`을 빌드 메타데이터로 확인했습니다.
- 모델 SHA256 `c53ef0386dfc8ee2422b2b9605b609b0c23315905599ecc2f4555c26de514b5f`.
- [검산 결과](result/audit.json), [파일 체크섬](result/SHA256SUMS), 원문·추출 문서·
  20개 stdout·명령/종료 상태·자원 기록·저장된 구성 파일을 보관합니다.
- [읽기 전용 검산](audit/main.go)은 실제 배열과 판단 입력 해시, 모든 사례의 정확한
  정수 값, 진행 기록 연결, 모델 호출 수, 네이티브 출력과 모델 없는 재실행을 확인합니다.
  모델 판단과 프로그램 실행을 새로 수행하지 않습니다.
- 큰 정수 결과의 1 차이, 결과와 기대값을 함께 바꾼 경우, 사례 배열 변경, 판단 연결 변경을
  거부하는 검산 테스트를 포함합니다. 검산 코드의 순번 기준과 JSON 공백 비교를 바로잡았고,
  원래 20개 명령과 관측 파일은 그대로 유지했습니다.

실행 흐름은 [사례 판단 모델 사용법](../../declared-contract-model.md)에 정리했습니다.

## Boundaries

The six canonical checks, reviewer-free governance mode and source authority
stay intact. The new branch's ownership registry lists only this release's
files. Model-free paths continue deterministically. A three-choice model is
never padded to fit the unary fixture, and preflight does not select code.

No model training or supplier model download accompanies this change. This
profile measures finite language behavior, not training independence, calibrated
confidence, language-wide completeness or host CPU utilization. First local
cases, consumed caller feedback and other evaluation inputs keep distinct
denominators. Whole-candidate-judge and source-IR-search preflight remain future
work. See the [release guide](../releases/0.6.24-dev.md) for exact commands.

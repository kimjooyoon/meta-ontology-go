# Semaprax에서 Gooo로 가져올 것

2026-10-12에 [저장소](https://github.com/wavect/semaprax)와
[소개 페이지](https://wavect.io/semaprax/)를 살펴봤습니다. 구현 확인 기준은
`933196b9ef3cb611343f1401e9eb0b08fa404d0a`입니다. 소개 페이지의 배포 기준은
0.8.0, 저장소 README의 개발 버전은 0.9.0이므로 두 범위를 구분해 읽었습니다.
코드를 빌드하거나 자체 성능 실험을 실행하지 않고 공개 소스와 검사 코드를 확인했습니다.

Semaprax는 소스의 선언에 안정적인 ID를 붙이고, 타입·계약·관계를 조회한 다음
정해진 수정 연산을 적용하는 흐름을 제공합니다. Gooo의 안정적인 ID, 의미 IR,
PROV-O와 본문 조립 계약에 가까운 문제를 다룹니다. 서로 다른 표면 문법보다
개발 도구가 필요한 정보를 얻는 방식에서 참고할 부분이 있습니다.

| 참고할 요소 | Gooo에서의 판단과 작업 |
| --- | --- |
| ID 중심의 제한된 문맥 조회 | 먼저 구현. 기존 IR에서 선언·본문·조립 계약과 이웃 관계를 가져오는 `context` 명령을 추가한다. |
| 잘린 문맥을 이어서 읽는 방식 | 함께 구현. 제외된 이웃 수와 다음 ID를 반환하고 원본 해시로 조회 사이의 변경을 확인한다. |
| 설치된 언어 안내와 진단 도움말 | 기존 `gooo help`에 새 명령 안내를 연결한다. 후속으로 진단 코드별 최소 수정 예제를 기존 진단 체계에 붙일 수 있다. |
| 새 프로젝트의 에이전트 안내 | 구현. app/library/diagnostic 스타터에 `AGENTS.md`를 넣어 실제 소스, 설치된 도움말, 조회·실행·재생 명령을 찾게 한다. |
| 작은 언어 기능을 호스트 언어에서 사용 | 기존 Go 패키지 생성과 ports 경로에 집중한다. Go 라이브러리와 연결되는 실제 예제가 우선이다. |
| 소스 요구와 구현 변경의 연결 | 기존 assembly 사례·선택지와 `body-construct` 결과를 연결한다. 원래 요구를 보존하며 후보를 고르는 현재 구조를 발전시킨다. |

## 첫 구현의 범위

[사용 가이드](../semantic-context.md)의 `context`는 결정론적 관계와 명시적 실행 바인딩을
양방향으로 조회합니다. 활동의 순서 있는 입력, 값 본문, 전체 조립 계약을 함께 반환합니다.
노드나 바이트 제한 때문에 계약의 일부만 노출되는 일을 피하려고 선언 단위로 선택합니다.
자체 소형 모델의 기존 입력 인코더와 모델 파일은 해당 활동의 `body-context`로 이어집니다.

기존 `query`는 관계 질의와 완전성 판정에 사용합니다. `context`는 일부 주변만 읽는
개발 흐름을 제공합니다. 일부가 생략된 정상 응답에도 생략 사실과 다음 조회 대상을 담습니다.
기존의 전체 질의 의미나 검증 정책을 바꾸지 않는 독립적인 읽기 명령입니다.

세 가지 프로젝트 스타터는 로컬 `AGENTS.md`도 생성합니다. 앱에서는 새 주변 조회를,
라이브러리와 진단 도구에서는 import와 record를 포함하는 기존 패키지 인터페이스를
안내합니다. 생성되는 소스와 검사 사례는 유지하고, 개발 도구가 읽을 안내를 추가합니다.
초기화에는 외부 모델 호출이나 문서 다운로드가 필요하지 않습니다.

## 뒤로 두는 부분

Semaprax의 ownership, Rust/C/Wasm 조합, 결제 가능한 런타임 Agent는 별도 언어·호스트
설계가 필요한 범위입니다. Gooo는 지금 Go 생태계 연결과 작은 결정 모델의 본문 조립을
발전시키는 것이 맞습니다. 새 실행 권한 체계나 리뷰 단계를 추가할 필요는 확인하지 못했습니다.

[공식 벤치마크 페이지](https://wavect.io/semaprax/benchmarks/)는 작은 예제에서 구조화한
문맥이 원본보다 커지는 반례와 측정 범위를 공개합니다. 따라서 이번 기능도 실제 JSON
크기와 개발에 필요한 정보 보존을 확인하고, 토큰 절약률이나 모델 정확도 개선은 후속
동일 조건 비교가 있을 때 평가합니다. 문서의 기능 목록만으로 우월함을 판단하지 않습니다.

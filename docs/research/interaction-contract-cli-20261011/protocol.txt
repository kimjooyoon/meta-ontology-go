and model identifiers in the local observation folder.

Fixed sequence, each command exactly once:

2. body-codegen without model: deterministic baseline, step size1.

6. body-outcomes-delta compares the saved native and replay outputs, with zero

Record complete stdout/stderr and exit status, /usr/bin/time -lp wall/user/system
seconds and maximum resident bytes for every command. Keep first-proposal outcome,
candidate attempts, declared output/condition counts, finite native counts, model

On any failure retain all preceding output, mark the step failed and stop; do not
silently retry the same observation. Later code corrections require a new stated

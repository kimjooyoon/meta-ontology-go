# 반복문 안에서 선언하는 카운터

Gooo의 횟수가 정해진 반복문에 다음 표기를 추가했습니다.

```gooo
let total=input
for let i=0;i<4;i++ {total=total+i}
for let i=0;i<3;i++ {total=total+i*2}
let i=43
return total+i
```

각 반복문의 `i`와 마지막 `i`는 별개의 변수입니다. 반복문에서 선언한 이름은
그 반복문 뒤에서 읽거나 대입할 수 없습니다. 같은 범위에 이미 있는 이름을
가리는 선언은 기존 `let` 규칙에 따라 거부합니다. 서로 떨어진 두 반복문은
같은 카운터 이름을 사용할 수 있습니다.

기존 방식인 `let i=0;for i=0;i<4;i=i+1 {...}`도 유지합니다. 기존 카운터를
사용하는 `for i=0;i<4;i++ {...}` 역시 단위 증가 형태입니다.

## 현재 범위

- 초기값은 0이며 조건은 `counter < 정수 리터럴`입니다.
- 상한은 1..1024입니다.
- 갱신은 `counter=counter+1` 또는 반복문 끝의 `counter++`입니다.
- 반복문 본문에서 카운터를 바꾸거나 같은 이름을 재선언할 수 없습니다.
- 중첩 횟수 반복문, 동적인 상한, 감소·임의 보폭은 후속 범위입니다.
- `++`는 이 반복문 갱신 위치에 지원합니다.

카운터는 Gooo `Integer`인 64비트 정수입니다. 현재 `len`의 Go 호환 반환은
`int`이므로 길이와 비교할 때는 `i<int64(len(input.values))`처럼 적습니다.
이 차이를 없애려면 이전 생성물의 재현성과 함께 언어 기본 연산을 정리해야 합니다.

## 원본 위치와 기원

`for let`은 토큰 편집으로 Go의 범위 있는 선언으로 내려갑니다. `++`는
작성한 연산 형태를 유지합니다. 계측할 때만 이전 값을 읽고 새 값을 쓰는
관측식으로 감쌉니다. 각 갱신은 같은 변수의 이전 쓰기를 한 번 읽습니다.

반복 실행 행에는 사이트 번호를 남기고 원래 `i++`의 좌표는 한 번 보관합니다.
조립 후보가 들어간 몸체는 원본·선택 조각의 길이가 달라질 수 있으므로 토큰
정규화 좌표를 거쳐 원본 위치로 돌아갑니다. 원래 식과 파일 편집의 일치 검사도
함께 적용합니다.

이 반복문으로 저장된 기록의 행을 직접 읽습니다.

# Toolchain conformance readiness

`TOOLCHAIN-CONFORMANCE` receives readiness credit only from one exact dynamic
`gooo/toolchain-conformance-report/v1` receipt. A concept row, individual green
tools, or an unknown top-level decision is insufficient.

Acceptance requires:

- 9/9 conformant surfaces
- 179/179 satisfied and executed source cases
- 151/151 satisfied source indicators
- 27/27 passed source proofs
- 13/13 fail-closed in-memory mutations
- 9/9 exact head bindings
- 0 unresolved observations, mismatches, writes, and mutation authorities
- 28/28 meta-bound conformance indicators
- 3/3 `FOUNDATION`, `COHERENCE`, and `REGRESSION` proofs

The fixed 24-obligation readiness transition is accepted only when the merged
baseline is 21/24 at 8750 basis points and the current receipt is 22/24 at 9166
basis points. The only admissible delta is +1 obligation and +416 basis points,
with zero regressions and zero unresolved evidence.

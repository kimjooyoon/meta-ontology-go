# Staged language semantic model

## Exact boundary

The semantic model is not credited because a Go type named `IR` exists. It is credited only when executable meta-code binds a fixed source set, lowers each source twice, normalizes both results, compares authoritative meaning, provenance, and exact evidence, then seals an effect receipt.

The versioned denominator is 22 cases. The exact target is 22/22 and 10000 basis points. The source component contains 17 `.gooo` files and 262 physical lines proven by the upstream syntax receipt. The 31-line source-splitter decision-algebra program, 20-line rollback-integrity activation program, 20-line vertical-slice closure activation program, and 17-line external-conformance activation program are credited only for lowering, normalization, and replay here; they do not establish runtime behavior or merge authority.

## Stages

1. `READ_SOURCE`
2. `PARSE_AST`
3. `LOWER_IR`
4. `NORMALIZE_IR`
5. `REPLAY_IR`
6. `SEAL_EFFECTS`

The observer has no repository mutation authority. Reads are listed per source. Writes, network operations, and child processes have a target of zero.

## Authority laws

- Presentation changes must alter the provenance-bearing canonical form while preserving the authoritative semantic hash.
- Candidate facts must be recordable without changing the authoritative semantic hash.
- Deterministic facts must change the authoritative semantic hash.

These laws connect the metric to `semantic.IR.SemanticCanonical`, not to a textual declaration of intent.

## Munchhausen choices

- `FOUNDATION`: bind the versioned 22-case registry and exact-head 19-case syntax receipt.
- `COHERENCE`: replay normalized IR, authoritative meaning, provenance, exact evidence, and the two positive authority laws.
- `REGRESSION`: reject invalid syntax, candidate authority escalation, unknown evidence, effects, writes, and mutation authority.

## gomacro reference boundary

[cosmos72/gomacro](https://github.com/cosmos72/gomacro) demonstrates a useful staged idea: macro functions operate on Go AST nodes before compilation. It also permits macro functions to perform ordinary Go effects such as file or network access. Gooo takes only the staged-structure lesson here. Future quote and expansion work must emit an explicit effect receipt and cannot inherit ambient mutation authority. No gomacro source code is copied and no novelty claim is made.

This receipt proves a semantic-model prerequisite. It does not yet claim macro expansion, runtime evaluation, deterministic query, Go interoperability, or package execution.

# Diagnostic provenance readiness binding

The binding joins four exact-head artifacts: language concepts, the fixed
18-case diagnostic report, the 24-obligation readiness snapshot, and the
binding artifact itself.

The first accepted transition is:

| Quantity | Before | After | Exact delta |
| --- | ---: | ---: | ---: |
| Completed obligations | 17/24 | 18/24 | +1 |
| Readiness basis points | 7083 | 7500 | +417 |
| Unresolved obligations | 0 | 0 | 0 |

The binding uses a fixed denominator of 24 and a cumulative floor of 18.
Future obligations may increase the numerator while this evidence remains
valid. The prior Go interoperation binding similarly uses its original floor
of 17, so adding diagnostic provenance does not invalidate that proof.

Twelve coordinates must bind, three Munchhausen proof choices must pass, and
effects, repository writes, and mutation authorities must all equal zero.

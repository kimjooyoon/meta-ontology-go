# 값을 갱신하는 표현과 출처

Gooo에서 초기화한 정수 지역 변수에 `+=`, `-=`, `*=`, `/=`를 사용할 수 있습니다. 조건 분기 안에서도 같은 규칙을 적용합니다. [실제 프로그램](../../examples/compound-updates/main.gooo)과 [입력 예제](../../examples/compound-updates/README.md)를 함께 제공합니다.

`amount += change`는 직전 `amount`와 `change`를 읽고 새 `amount`를 만드는 작업입니다. Gooo는 이 관계를 타입과 경로 레시피, 원래 소스 위치, 실행 시점의 지역 변수 기록에 연결합니다. 단축 표기에서도 값의 기원이 이어집니다.

코드 생성 단계에서는 네 연산자를 기존 이항 연산과 할당 경로로 정규화합니다. Go 출력에는 작성한 갱신 표기를 보존합니다. 실제 실행에서는 이전 값을 읽은 뒤 새 값을 쓰는 순서를 관찰합니다.

작성한 프로그램의 새 입력 네 사례는 모두 맞았습니다. 각 실행의 쓰기와 읽기를 합쳐 16회씩 기록했고, 직전 값과 최종 반환값의 출처를 확인했습니다. 모델 호출은 0회였습니다. 이 수치는 해당 네 사례의 결과입니다.

현재 허용 대상은 초기화된 직접 정수 지역 변수입니다. 입력 포트 갱신, 정의되지 않은 변수, 레코드 필드의 복합 갱신에는 별도 언어 규칙이 필요합니다.

[관찰 기록과 등록 출처](../observations/compound-updates/README.md)에 원래 실패한 입력 봉투와 새 입력의 실행을 구분해 보관했습니다. 언어 등록은 Gooo의 기존 등록 계약으로 아홉 산출물 역할을 생성해 수행했고, 과거 분모 파일은 보존했습니다.

# Mangle과 비교하며 보완할 Gooo의 설명

2026-10-13에 공식 문서와 공개 소스를 읽은 기록이다.
[Mangle](https://github.com/google/mangle)은 Datalog를 확장한 관계 추론 언어이며,
Go 라이브러리로 애플리케이션에 넣을 수 있다. 여러 데이터의 사실과 규칙으로 도메인을 표현한다.
Google에서 시작했고 현재 독립적으로 개발된다. 공식 README는 Codeberg가 원본이며
GitHub가 미러라고 설명한다. 프로젝트의 향후 성공 가능성은 이 자료만으로 단정하기 어렵다.

최근 원본과 연결된
[eabbd48 수정](https://github.com/google/mangle/commit/eabbd4817c227ed8aaba5160659fd116f82b5238)은
같은 해시를 가진 사실을 값의 동등성 비교로 구분하도록 바꿨다.
읽을 교훈은 표시·색인용 값과 의미의 동일성 판정을 구분하는 것이다.
Gooo의 명시 ID와 타입 구분을 점검할 참고 사례로 두며, 이 외부 수정만으로
Gooo에 같은 결함이 있다고 판단하지 않는다.

## 직접 참고할 기능

Mangle의 [provenance 안내](https://mangle.readthedocs.io/en/latest/provenance.html)는
어떤 규칙과 원래 사실로 결과를 유도했는지 보여 준다. 근거 그래프를 다시 사실로 내보내
질의할 수 있다. 설명의 수·깊이에 한도를 두고 일부 설명은 partial로 남긴다.
이 원리를 Gooo의 조건·선택·관찰을 읽는 방법에 적용할 수 있다.

Mangle이 프로그램의 사실을 유도하는 역할과 Gooo가 소스의 후보를 조립하는 역할에는
겹치는 요구가 있다. 결과 하나의 근거를 읽는 사용자 관점에서 공통 과제를 정한다.

| 같은 요구 | Mangle 공식 자료에서 읽은 표현 | 현재 Gooo에서 확인한 범위 |
| --- | --- | --- |
| 도메인 개념과 관계 | 여러 인자를 가진 사실·규칙, 구조화된 값과 타입 표현. | entity·field ID와 typed activity 연결. flat record native 범위. |
| 결과의 이유 | 규칙, 변수 값과 원래 사실을 연결한 proof graph. | 활동·필드 ID, 입력·출력, 소스 후보·사례 결과를 기록. 분기별 자동 설명은 후속 요구. |
| 구현 선택 | 명시한 규칙으로 새 사실을 유도. | 소스가 후보와 빈자리, 선택·별도 평가 사례를 소유. 작은 모델은 지원 프로필에서 판단을 제안. |
| 표현 범위 | 공식 문서의 리스트·맵·구조, 집계·재귀 관계. | 레코드 필드는 여러 개, 각 필드 값은 정수·문자열·불리언 하나. 중첩·집합 표현은 보완 대상. |

Mangle의 기능은 문서·소스 분석 결과다. 이번 작업에서 설치하거나 실행하지 않았다.
다른 엔진에서 같은 입력을 실행하기 전까지 속도·정답률·외부 코드량은 미관측으로 둔다.
더 넓은 Gooo 표현과 소형 모델의 학습 성과도 현재 관찰과 구분한다.

## 먼저 만든 공통 업무 과제

[재고 요청 판단](source-decision-reasons.ko.md)은 Gooo가 승인 여부와 이유,
요청 번호를 함께 조립하는 과제다. 후보 3개를 타입에 맞게 구성하고,
이유가 틀린 후보를 선택 사례에서 구별했다. 별도 사례와 실제 호출도 확인했다.
현재 Gooo의 진전은 새 Go 구현 없이 이 요구를 Gooo 소스와 기존 구성 경로로 표현한 점이다.

다음 보완은 이유 문자열에서 실제 소스 근거까지 이어가는 일이다.
수량과 재고를 읽은 입력, 성립한 조건의 위치·활동 ID, 반환 필드 ID를 연결하는
관찰을 설계한다. 미지원 조건과 기록 한도 때문에 빠진 근거도 읽을 수 있어야 한다.
설명 기록을 다시 Gooo의 판단 활동이 읽는 방식은 그다음 작은 메타프로그래밍 과제로 둔다.

[공통 비교 기준](../ontology-language-comparison.ko.md)의 요구 표현, 의미 유지,
실제 결과, 설명 범위와 외부 구현량을 각각 기록한다. 새 언어를 고를 때도
최근 개발 내용과 사용 가능한 예제를 확인하고, 같은 작은 요구부터 맞춘다.

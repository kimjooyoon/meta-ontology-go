# Design-only metric catalog

Status: `DESIGN_ONLY`. This catalog names initial metric questions and their
deterministic contracts; it does not add an evaluator, verifier, workflow,
protection rule, merge rule, or blocking check. The common `DecisionMetric`
fields in [metrics-rfc.md](metrics-rfc.md) remain authoritative.

Every row uses the same failure rule: missing or ambiguous authority input,
resolution, witness, or snapshot binding is `UNKNOWN`, never `PASS`.
`NOT_APPLICABLE` is valid only when the immutable catalog row proves it for the
same snapshot. `UNOBSERVED` means that no exact-bound retained evidence exists
for this catalog row; it is not a claim that the row is impossible to observe.
No row below is `BLOCKING`.

Coverage denominators are immutable declared question, input, and obligation
sets; a zero denominator is never reported as 100%.

Observability is grounded in checked-in `origin/dev` views only: the RFC and
governance contract, the current semantic/compiler sources, and the checked-in
CI policy. `NOW` means an exact source-backed observation exists; `PARTIAL`
means at least one required input or witness is not yet exact; `MISSING` means
the observation has not been defined or retained. These labels do not claim
that an existing check implements the metric.

# Source-relative compiler context and explicit training export

The optional own model ranks declared typed alternatives. Source binding and
finite functional observations remain separate authority. Context schema
`gooo/compiler-typed-path-context/v2` is a semantic text format; the unchanged
feature ABI is `split_context_intent_ngrams_v2`. Existing v1 evidence remains
valid at its pinned revisions. Reusing existing v2-feature weights is a baseline,
not evidence that those weights were trained on compiler context v2.

## Source-relative alternatives

The compiler snapshots the original fallback without changing the search base.
Each input includes result type, decision kind, target, explicit fallback label,
`basis=source_fallback`, one-hop typed node facts and legal alternatives.
Operand/branch `reverse_source` is the option's reverse flag XOR the fallback's
reverse flag. Reference/assignment options name their destination; root options
show actual statement indices. The search plan retains its original meaning.
Normalizing the actual search base would apply reversed fallbacks twice.

The suffix after the last literal `intent: ` remains intact. Compiler facts
replace the caller prefix. Source identity and semantic hashes stay in receipts,
not learnable arbitrary identifiers. Initial inputs exclude expected values,
finite pass counts and CI outcomes. Byte overflow is a representation decline;
there is no silent truncation. All optional ranking is skipped on any decline,
with the existing deterministic finite search and partial body receipt retained.

## Export command

```sh
gooo body-context --plan plan.json --activity ChoosePath source.gooo
```

JSON schema `gooo/compiler-path-input-export/v1` contains explicit input text,
full byte counts and hashes, original source/document/test-suite bindings,
compiler context receipt and timing. This is the same encoder and shared source
binding used by `body-codegen --path-plan ... --path-model ...`.

Export emits and typechecks original/fallback **validation projections**. It
makes zero model predictions, performs zero candidate tests, emits no selected
candidate, makes no repository writes and applies no sampling seed. Typed plan
validation still checks its envelope and declared alternatives. The original
fallback must match the authoritative source before text is exported. Invalid
source, cancellation or a mismatched fallback fail closed. Representation decline
exports an empty input-text array with diagnostic hashes and full attempted size.

Text is disclosed only by the explicit command/API, not normal generation
receipts. Public training must use deliberately selected public/synthetic inputs.
Export does not redact text automatically or authorize uploading caller sources.

## Evidence and limits

Unit tests compare all six conditional decision inputs in both languages with
actual native generation receipts, verify hashes, preserved natural suffix,
source-relative reversed fallbacks, atomic overflow decline, target/seed isolation,
cancellation, source mismatch, command dispatch and ambiguous flag rejection.
Existing retained concurrency tests still exercise independently owned requests.
This is a bounded compiler-input contract, not a full semantic IR encoder,
universal correctness theorem or unrestricted code generation model.

기능 정답률을 측정한 코호트가 아니다. 실제 입력 전용 Gooo 소비자의 두 출력
행을 기원 자료와 대조했다. 원래 후보 프로그램 실행·모델 호출은 0이다.
각 소스의 당시 압축본·목록·시작·종료·로그를 [색인](index.json)에 보관한다.
완료된 과거 로컬 코호트를 다시 실행하지 않았다.

## 실패를 남기고 수정한 부분

27401은 모든 변경 함수 30개를 확인하다가 전체 사례를 한 함수에 둔
`expectedRegistry`의 162줄을 발견했다. 상한을 바꾸지 않고 동일한 110개 사례를
여섯 개의 순서 있는 그룹으로 나누고 패키지 정의를 그대로 옮겼다. 필요한 함수
모집단도 새 도우미를 포함한 38개로 늘렸다. 27537·27593은 다른 새 소스 검사다.

27671 정적 검사는 임베딩된 입력 구조체 리터럴에 Go 1.27의 승격 필드 문법을
제안했다. 같은 19개 필드·태그·값·제한을 유지하며 문법을 반영했다. 최종 27803
정적 검사는 제안 없이 끝났다. 원래 두 실패·제안과 당시 소스를 보존한다.

## PR1563의 원래 결과

원래 실행 29개는 성공 26개·실패 3개로 모두 종료됐다. 네 플랫폼의 네이티브
빌드·실행·재실행과 준비도는 그 소스에서 성공했다. 이는 후속 소스의 수용 근거로
빌려 쓰지 않는다.

단위 검사 `115815995202`의 원래 로그는 다음 두 실제 파일이 문법 목록에
등록되지 않았음을 보여준다.

- `examples/fill-candidate-origins/inspect.gooo`
- `examples/fill-candidate-origins/source.gooo`

후속 소스는 그 두 파일과 새 문법 후보의 두 파일을 모두 정식 언어 사례로
등록한다. 파일을 빼거나 보호 검사를 낮추지 않았다. 전체 사례는 유효 107개와
무효 3개이며, 언어 기능 108개와 운영 관찰 2개의 구분을 유지한다.

의미 적합성 작업 `115815995171`도 실패했다. 그 원래 로그는 별도의 소스 원인을
구체적으로 기록하지 않았으므로 단위 검사의 원인을 그대로 단정하지 않는다.
동시성 작업 `115815995159`은 기존 20분 제한에서 취소됐다. 원래 기록과 결과를
보존한다. PR1563은 head/body를 바꾸지 않고 병합 없이 닫았다.

기존 213개 쓰기 경로를 전부 보존하며, 명령·안내는 문법 후보를 읽도록 확장한다.
후속 소스는 자신이 제출한 수정 전체에 대한 원래 CI·증명·네이티브 결과가 필요하다.

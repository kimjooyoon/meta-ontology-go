24731의 저장 결과는 정상 위치 두 행이 `DECLARED_ASSIGNMENT`, 다른 입력의
두 행이 `UNRESOLVED_USE`와 `DECLARED_ASSIGNMENT`로 나왔습니다. 이는 Gooo가
전달받은 위치 자료를 해석한 네 출력 행의 대조입니다. 후보의 기능 정답률은
측정하지 않았습니다. 입력 전용 소비자의 `finite_total=0`, 모델 호출은 0이며,
후보 원본 프로그램은 실행하지 않았습니다.

각 코호트의 소스 압축본·목록·시작·종료·로그와 [색인](index.json)을 보관합니다.
완료된 과거 코호트를 로컬에서 다시 실행하지 않았습니다.

현재 소스의 최종 정적 검사 25871도 전체 변경 Go 코드 28개에서 수정 제안·
오류 출력·테스트 실행 0으로 끝났습니다. 25717과 25871의 소스 압축본에는
앞선 관찰 압축본을 다시 넣지 않아 중첩 압축본의 증가를 줄였습니다.

## 실패한 검사와 수정

- 24817은 새 어댑터의 한도를 외부 IR의 16개로 잡았고 검사 소스도 16개를
  선언했습니다. 기존 Gooo 파서가 9번째 빈자리에서 거부했습니다. 새 어댑터와
  안내를 기존 소스 문법의 8개에 맞췄으며, 파서와 의미 제약은 바꾸지 않았습니다.
- 24919는 경계 검사 소스에 후보를 하나만 선언했습니다. 기존 소스 계약은
  2..16개의 완전한 후보를 요구합니다. 서로 다른 이름·ID·사례의 25037은 두
  후보를 선언하고 8개 보존·9개 거부를 확인했습니다. 이 수정은 검사 자료입니다.
- 25207 정적 검사는 새 검사 자료를 만드는 세 반복문에 정수 `range` 사용을
  제안했습니다. 생산 코드 차이는 없었습니다. 검사 반복문을 고친 뒤 전체 소스의
  25441 정적 검사가 수정 제안 없이 끝났습니다. 앞선 검사 코호트는 재실행하지
  않았고 당시 실패·제안과 소스를 그대로 보관했습니다.

## 공개 PR1562의 원래 업로드 실패

원래 네이티브 실행 `38547914090`의 macOS Intel 작업 `115798451299`은
빌드·실행·재실행 단계가 성공한 뒤 결과 업로드에서
`Failed to FinalizeArtifact: Unable to make request: ENOTFOUND`를 기록했습니다.
최종 준비도는 실패했습니다. 앞선 PR1561의 `CreateArtifact` 실패와 이번
`FinalizeArtifact` 실패를 각 원래 로그로 구분해 남깁니다.

원래 전체 CI가 필요한 상태이며, 실패한 업로드를 전체 준비도 통과로 바꾸지
않습니다. 공개 head/body와 워크플로, 검사와 시간 제한은 유지했습니다.
이후 제출할 완전한 후속 소스는 그 자신의 원래 CI가 필요합니다.

원래 동시성 검사 `115798452021`은 20분 제한으로 취소됐습니다. 원래 로그에
CLI 535.882초, 본문 생성 176.814초, 본문 실행 558.826초, 실제 CLI 관찰
254.248초의 패키지 통과가 남았습니다. 추출기 패키지의 완료 기록과 데이터
경쟁 경고는 관찰되지 않았습니다. 특정 소스가 시간 초과를 일으켰다는 인과
결론은 이 로그로 확인되지 않았습니다. 검사와 시간 제한을 줄이지 않았습니다.

원래 29개 실행은 성공 27개·실패 1개·취소 1개로 모두 끝났습니다. 형식·
정적 분석·단위 검사·의미 적합성·정책은 성공했고, 동시성 검사는 취소됐습니다.
PR1562는 head/body를 유지하고 병합 없이 닫았습니다.

저널 연결의 해시는 갱신하지 않아 거부됐습니다. 도우미 검사에서는 시작 순서와

## PR1561의 원래 네이티브 준비도

원래 실행 `38539249227`에서 네 플랫폼의 빌드·실행·재실행 단계는 성공으로
기록됐습니다. macOS Intel 작업 `115769640430`의 결과 업로드는
`Failed to CreateArtifact: Unable to make request: ENOTFOUND`로 실패했습니다.
최종 준비도 `115772129291`도 실패했고, 취합 단계는 건너뛰었습니다.

원래 동시성 작업 `115769643471`은 20분 제한으로 취소됐습니다. 그 로그에는
CLI 535.067초, 본문 생성 177.895초, 본문 실행 564.678초, 실제 CLI 관찰
247.951초의 패키지 통과가 있습니다. 추출기 패키지의 완료 기록은 취소 전에
남지 않았습니다. 이 로그는 작업별 세부 테스트 시간이나 취소 원인의 소스
의존성을 직접 증명하지 않습니다. 기존 시간 제한과 검사 집합은 유지합니다.

원래 29개 작업은 성공 27개·실패 1개·취소 1개로 모두 끝났습니다.
형식·정적 분석·단위 검사·의미 적합성·CI 정책은 성공했고 동시성 검사는
취소됐습니다. PR1561은 head/body를 바꾸지 않고 병합 없이 닫았습니다.
[종료된 원래 작업 기록](predecessor1561/terminal-originals.json.gz)을 보관합니다.

원래 작업의 실패는 그대로 남깁니다. 로그에서 보고한 원인은 업로드의 이름
해석 실패이며 소스 결함은 확인되지 않았습니다. 필요한 원래 자료가 없는 상태를
전체 통과로 취급하지 않습니다. 공개 head/body와 워크플로를 유지했습니다. 모든 원래 작업이 끝난 뒤
완전한 후속 소스를 별도 PR로 제출합니다. 후속 소스는 그
자신의 원래 네이티브 결과와 전체 CI가 필요합니다.

후속 변경은 시작 프로젝트의 기존 32개 경로를 모두 포함합니다. ID 선택과
기원 해석·분모 표기를 추가하며, 필수 검사나 업로드 정책을 변경하지 않습니다.

## 초기 실행에서 확인한 사항

20217은 업무 입력 3/3과 필드 위치 6개 확인 뒤, 검사가 생성물의 필드 표기를
원본 식으로 읽어 실패했습니다. 원본 식의 위치는 `Source.Value`에 있습니다.

20423은 새 입력 3/3까지 진행하고 전체 기록을 저장했지만, 기원 관찰에서
길이 지역 변수의 누락을 발견했습니다. 기존 `int` 길이 변수는 Integer 지역
변수 기록 대상에 들어가지 않았습니다. 실제 Integer 불일치를 해결하는 새
프로그램의 길이 변수를 Integer로 맞추고, 새 소스·입력 20809에서 계산과
원본 길이·필드 위치 확인을 함께 통과했습니다. 앞선 두 코호트는 실패로 남깁니다.

## 공개 PR 1558의 원래 CI에서 확인한 사항

원래 동시성 검사는 성공했습니다. 원래 투영 자료의 추출은 1019/1019,
생성 도우미 2880개, 미처리 0개입니다. 논리 파일 분리가 끝난 뒤 테스트 두
개가 원래 파일만 읽으면서 필요한 선언 2개 중 0개, 25개 중 7개를 찾았습니다.

수정안은 패키지·수신자·함수 이름으로 같은 선언 집합을 찾습니다. 두 재생 함수를 요구하며, 기존 최소 20개 검사에서 실제 관측한 25개 함수를
명시적 대상으로 모두 요구합니다. 생성 크기 상한을 유지하고 누락·중복을 거부합니다. 새 파일 배치
검사 21107을 별도로 실행했습니다. 완료한 두 과거 코호트는 로컬에서 다시
실행하지 않았습니다. 의미 검사도 실패했으며, 제공된 로그는 투영 후 전체
테스트 결과를 별도 파일로 보내 상세 실패를 직접 보여 주지 않습니다.

원래 PR의 head/body·워크플로·시간 제한·필수 체크는 유지합니다. 원래 실행을
재실행하거나 취소하지 않았습니다. 원래 전체 작업이 종료된 뒤의 완전한
후속 변경으로 적용해야 합니다.

## 남은 범위

이미 유효한 길이 변수의 호스트 `int` 표현은 보존합니다. 그 경로의 기원
기록 확장은 별도의 호환성 범위입니다. 동적·중첩 반복문, 감소 보폭,
문자 단위 길이, 전체 레코드 복사와 컬렉션 원소의 완전한 인과 연결은
추가 언어 작업으로 남습니다.

## 먼저 실패한 입력

- 16167: `for let` 초기화 구문이 현재 프로필 밖이어서 파싱에서 중단했습니다.
- 16223: 카운터의 `++` 갱신을 현재 제한된 `for` 프로필이 거부했습니다.
- 두 경우 모두 네이티브 생산 실행 전에 중단했습니다. 16301은 새 ID·새 입력을
  사용하고 선언된 카운터와 `counter=counter+1` 구문으로 관찰했습니다.
- 16941: 새 패키지를 Go overlay로 추가했지만 vet의 실제 작업 폴더가 없어
  빌드에서 중단했습니다. 빈 폴더를 만들고 vet를 유지한 채 새 소스 17011을 검사했습니다.

원래 실패의 로그·스냅샷과 다음 입력의 결과를 함께 보관합니다. 반복문 설탕
구문 지원은 별도 언어 사용성 과제로 남겼습니다.

## 원래 CI의 시간 초과와 후속 구성

PR 1556의 원래 동시성 검사에서 CLI 패키지가 기본 600초에 도달했습니다.
당시 실행 중이던 개별 하위 검사는 1초였습니다. 직전 통과한 PR 1555의 같은
패키지는 564.925초였습니다. 과거 기록은 원인 비교에만 쓰며 새 PR의 승인에
사용하지 않습니다.

후속 구성은 동일한 12개 필드 기원 검사를 세 입력씩 네 명령으로 묶습니다.
무거운 명령 관찰은 `internal/cliobservations`에서 실제 실행 파일을 호출합니다.
`go test -race`에서는 그 실행 파일도 `-race`로 만듭니다. 검사 항목과
기존 CI 시간 제한을 유지합니다. 완료한 과거 테스트는 로컬에서 재실행하지
않으며 후속 PR의 원래 CI가 전체 검사를 담당합니다.

이후 CI의 통과 여부는 해당 PR의 자체 실행 결과로 확인해야 합니다.

# 필드·지역 변수의 교차 기원 관찰

## 새로 표현한 경로

필드에서 꺼낸 값을 지역 변수에 저장하고, 원래 필드를 바꾼 뒤 저장한 값으로
다른 필드를 구성하는 경로입니다. 실제 실행의 쓰기 참조를 보관하고 Gooo가
두 종류의 기록을 따라갑니다. 조회 중 원래 생산 프로그램을 실행하지 않습니다.

스칼라 변수에 레코드·필드 ID를 붙이지 않습니다. `scalar_local`, 선언 순번,
이름과 원시 타입을 전달합니다. 두 기록의 프레임 번호는 독립적으로 유지하고
공통 완료 시계와 실제 읽기 참조로 이어 줍니다.

분모가 다른 결과를 하나의 언어 정답률로 합치지 않습니다. 합성 입력은
네이티브에서 생성됐다고 주장하지 않습니다. 입력만 받는 소비자는
`OBSERVED`, `finite_total=0`이며 위 비교는 외부 테스트의 기대값과 대조했습니다.
모든 집단의 모델 호출은 0회입니다. 기존 완료 집단을 로컬에서 재실행하지 않았습니다.

15217 생산 기록에는 필드 쓰기 80개·지역 변수 쓰기 26개,
필드 읽기 74개·지역 변수 읽기 24개와 교차 읽기 구간 26개가 남았습니다.
선택한 마지막 필드들은 원래 필드를 덮어쓴 뒤에도 저장 당시의 입력 기원으로
돌아갔습니다. 실제 반환 튜플도 함께 확인했습니다.

## 보관 누락을 다룬 범위

15641은 한 번의 유한 반복 안에서 변수 저장과 필드 대입을 반복합니다.
같은 변수 읽기를 포함한 산술식으로 읽기 보관 상한도 확인했습니다.

| 보관·동작 | 실제 기록 |
| --- | ---: |
| 필드 쓰기 | 4,096 |
| 지역 변수 쓰기 | 4,096 |
| 공통 완료 | 8,192 |
| 필드 읽기 | 32,772 |
| 지역 변수 읽기 | 65,536 |
| 누락 필드 쓰기 | 28,676 |
| 누락 지역 변수 쓰기 | 30,726 |
| 누락 지역 변수 읽기 | 102,402 |
| 실제 결과 | 16,485와 16,595 |

기록 상태는 `PARTIAL`입니다. 기록에서 빠진 쓰기의 값을 추정하지 않았습니다.
원래 계산은 계속됐고 기대한 두 값이 나왔습니다. 소비자 크기 상한은 합계
60개 쓰기·128개 읽기이며 큰 기록은 잘라서 전달하지 않습니다.

15617에서는 한 케이스의 중단을 다른 정상 케이스의 보관 상태에 섞지
않았습니다. Gooo 소비자에서도 정상 케이스는 범위 안의 연결 결과를,
두 실패 케이스의 선택된 읽기는 `PARTIAL_RECORDING`을 반환했습니다.

## Gooo가 맡는 부분과 남은 범위

Go는 원래 기록을 검증하고 두 읽기 구간을 열로 전달합니다. 단순 상수는
보관된 타입 표현식의 구문으로 표시합니다. Gooo가 공통 완료 순서의 역순
탐색, 직접 부모 우선 연결, 입력 기원 선택과 미해결 상태를 계산합니다.

컬렉션 기원이 미해결인 스칼라 쓰기에서도 알려진 필드·지역 변수 참조를
계속 따라갑니다. `collection_rhs_writes`와 `unresolved_links`는 남은 부분을
보여 줍니다. 예전 비공개 읽기 제안 15437은 교체한 상태로 보존했고,
다른 소스 해시의 15901이 수정된 소비자를 등록했습니다. 15401의 생산 예제
등록은 재실행하지 않고 생성 바이트를 그대로 사용했습니다.

등록은 64→65→66, 각 9개 역할·9개 멤버입니다. 최종 코퍼스는 101개
(유효 98·무효 3), 언어 기능 99·거버넌스 관찰 2, 네이티브 기원 소비자 10개입니다.
이 수치는 해당 제출에서 확인할 대상을 뜻합니다.

분기 제어, 헬퍼 인자·반환의 정밀 선택, 활동 그래프 사이의 레코드 부모,
컬렉션 원소 기원의 통합과 큰 기록의 페이지 순회는 남아 있습니다.
평가 중 읽힌 값의 참조를 따라가는 현재 범위를 유지해서 해석합니다.
저장 자료의 해시는 출처 참조이며 생산자의 신원 인증을 뜻하지 않습니다.

[manifest.json](manifest.json)은 최초 빌드 실패, 각 집단의 소스 스냅샷,
시작·종료 기록, 압축 결과, 등록 요청과 생성 멤버의 해시를 연결합니다.
이전 PR1555의 원본 CI37개·검증 자료를 확인하고 승인된 `dev` 트리와
관찰 기준 트리가 같은 상태에서 후속 변경을 구성했습니다.

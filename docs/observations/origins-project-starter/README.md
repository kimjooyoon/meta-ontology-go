# 기원 조회 시작 프로젝트 관찰

새 `origins` 시작 프로젝트의 분류 규칙은 `inspect.gooo`에 있습니다. CLI는 다섯
시작 파일과 공통 AGENTS 안내를 실행 파일에 담고, 모듈 경로를 적용해 새 폴더를
만듭니다. 모델이나 별도 다운로드를 생성하지 않습니다.

| 관찰 | 확인한 범위 | 결과 |
| --- | --- | --- |
| 23117 생성 | 기본 모듈·사용자 모듈, 안내·소스·입력 등 여섯 파일 | 고유 ID 적용과 미치환 표기 부재 확인 |
| 23117 기존 폴더 | 같은 생성 요청 재시도 | 기존 소스 유지 |
| 23117 모듈 경로 | 잘못된 경로 세 가지 | 폴더를 쓰기 전에 거부 |
| 23117 연습 사례 | 가상의 출처 입력 네 가지 | 예상 출력 4/4 |
| 23117 이동 | 프로젝트와 저장 결과를 옮긴 뒤 입력만 변경 | 새 입력 1개 관찰, 정확도 분모 0 |
| 23117 실제 저장 기록 | 이전 22133 생산자의 첫 9/27행 | 대안 3·필드 대상 3·미해결 3; 페이지 범위 유지 |
| 23303 정적 검사 | 최종 Go 코드 여섯 파일, Go 1.27.2 | 수정 제안·오류 출력 0; 테스트 실행 0 |

연습 사례는 `demo.gooo`와 `SAMPLE_SOURCE_ID`를 사용한 명시적인 가상 입력입니다.
실제 저장 기록 조회는 별도 경로이며, 원래 생산 프로그램과 모델을 호출한 횟수는
각각 0입니다. 이 조회 결과에는 예상값을 넣지 않아 기능 정확도 분모도 0입니다.
전체 27행 가운데 선택한 아홉 행을 읽은 범위를 그대로 표시합니다.

`starter23117`와 `static23303` 폴더에는 당시 소스 압축본·해시 목록과 시작·종료
기록, 로그가 있습니다. 연습·이동 후 입력·실제 조회의 결과는 압축 JSON으로
보관합니다. 완료된 과거 코호트를 로컬에서 다시 실행하지 않았습니다.

## 초기 실패도 보존

- 21511: 선택용·보류 1/1과 실제 3/3 뒤 필드 조회 실패. 직접 반환 생성자에
  이름 있는 지역 변수가 없어서 필드 관찰 주체가 없었습니다. 반환식 주체를 추가했습니다.
- 21673: 실행 시 파일 읽기는 Go 오버레이가 대신하지 않습니다. fixture를 여는
  경로가 잘못되어 생산자·모델 실행 전에 종료됐습니다. 21737은 동결된 fixture 경로를 씁니다.

  해석된 식을 직접 비교했습니다. 21917은 두 범위를 구분합니다.
- 22049: 선택된 식을 감싸는 괄호의 길이를 빠뜨려 생성 단계에서 종료됐습니다.

## PR 1559의 원래 CI

37개 원래 작업 중 36개는 성공했고 핵심 CI는 취소로 끝났습니다. 핵심 작업의
동시성 검사는 20분 제한에 도달했으며, 연결된 증거·증명 작업도 실패했습니다.
단위 테스트·의미 검사·형식·정적 검사·정책과 별도의 투영·네이티브 준비도·CodeQL은
성공했습니다. 이 상태를 수용 가능한 전체 통과로 취급하지 않습니다.

새 소스는 AST에 실제 `len` 호출이 없을 때 길이 표현식용 추가 자료형 검사를
생략합니다. 문자열과 주석은 호출로 세지 않습니다. 전체 동시성 검사 시간의
개선 여부는 이 후속 공개 소스 자신의 원래 CI로 확인해야 합니다. 시간 제한,
필수 검사와 워크플로는 바꾸지 않았습니다.

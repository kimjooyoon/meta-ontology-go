# 원래 파일까지 이어지는 지역 변수 기원

기준 개발 소스는 `e1c2938de8fc588c63210eea3ebe3df848abc2c5`다.
변경 소스와 입력은 각 스냅샷으로 구분한다. 완료된 과거 로컬 소스·테스트·모델 묶음을
다시 실행하지 않았다. 아래 수치는 해당 입력의 관찰 범위다.

새 생산·재실행 입력은 합계 12개다. Gooo 읽기 출력은 합계 108개를 대조했다.
읽기 실행 자체는 기대값 없는 `OBSERVED`와 finite 분모 0을 유지한다.
이를 언어 전체의 정답률이나 독립 실험 108개로 세지 않는다.

정적 파일 표는 실제 대입·사용 위치와 별도로 남는다. 기존 위치 ID와 관찰 집계는
바꾸지 않는다. 이름 변경을 되돌리기 전 선택 표현이 템플릿 구간과 일치하는지 확인한다.
페이지 선택에는 정수 인덱스 배열을 한 번 만들고 여러 사례에서 공유한다.
선언·대입·사용의 정확한 원본 구간과 후보·문법·템플릿 문맥의 구간을 구분한다.
원래 후보 식이 없는 파생 문법에는 후보 식의 위치를 붙이지 않았다.

12673은 파일 정보가 없는 저장 형식을 현재 소스와 다른 입력으로 새로 실행했다.
새 실행에는 파일 위치가 생기지만 과거 기록의 빈 필드를 수정하지 않았다.
정수·문자열·불리언 지역 변수라는 기존 관찰 범위, 기록 한도와 부분 상태는 유지한다.
최소 인과관계나 중첩 값 전체의 기원을 이번 결과로 확정하지 않는다.

[실행 묶음](runs.json), 소스 manifest·압축 스냅샷, 원래 로그와
[출력·추출 해시](outputs.json)를 보관한다. 공개 런타임은 원래 결과의 `runtime` 또는
CLI 결과의 `result.runtime` 값을 UTF-8 JSON으로 다시 저장한 것이다. 원래 CLI 전체의
해시와 추출 파일 해시는 구분한다. 파싱 실패 로그의 임시 경로만 표시용으로 치환했다.
등록 도구 출력은 수정 없이 보관했고 사용한 임시 실행 파일은 삭제했다.

## 앞선 공개 제출의 원래 실패

PR #1551의 원래 진행 현황 검사에서 PR 546·562·569의 실행 목록 조회가 HTTP 500을
반환했다. 이 세 오류가 여섯 미확정 칸으로 이어졌다. 보고서 재현과 생성 Gooo 파싱은
완료됐지만 결과가 `LOWER_RESOLUTION`이어서 기존 진행 조건을 통과하지 못했다.
[원래 실패 요약](predecessor1551-failure.json), 그 실행의 관찰·보고서·생성 프로그램을
함께 보관한다. 원래 워크플로를 다시 실행하거나 그 결과를 바꾸지 않았다.

후속 관찰 요청은 HTTP 500·502·503·504에서만 최대 두 번 더 읽는다. 각 재시도는
원래 작업 로그에 남는다. 권한·없는 리소스·할당량 오류를 예외 처리하지 않으며,
고정 PR 묶음, Gooo 판단, 보고서 재현·파싱과 기존 진행 조건도 유지한다.
최종 통합 여부는 후속 제출의 원래 CI에서 확인한다.

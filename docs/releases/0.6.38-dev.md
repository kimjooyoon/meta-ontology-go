# Gooo 0.6.38-dev

This development prerelease is built from [source `32ac610`](https://github.com/kimjooyoon/meta-ontology-go/commit/32ac61006761f8759468436e7cdd91883cf24431) with Go 1.27.3. The [release](https://github.com/kimjooyoon/meta-ontology-go/releases/tag/v0.6.38-dev) contains four native platform archives, `SHA256SUMS`, and the publication records. The compiler pins decision runtime `v0.2.51-experimental`.

## Try a program

The [first-program guide](../getting-started.md) installs this exact version, creates a diagnostic package, runs its finite cases, and replays the saved program with new inputs. It needs no model or API key. `gooo version --build --json` reports the compiler version, Go toolchain, and installation identity. The native archive reports the source commit above with `CLEAN_VCS`; a module installation reports its module version and checksum while VCS identity can be unobserved.

Native execution needs Go 1.27.3. Saved-receipt inspection uses the matching Gooo binary. Keep older binaries when replaying records from earlier source revisions rather than changing their recorded toolchain identity.

## What this source adds

- `map_values` applies a named Gooo activity to each item in a bounded scalar collection while retaining input order, duplicates, and each attempted item's source origins. The [collection example](../../examples/collection-map/README.md) describes the 256-item profile and its finite checks.
- The [scope-fragments example](../../examples/scope-fragments/README.md) derives JSON, Go, and Markdown registration fragments from one Gooo input. The caller decides whether to apply the proposed text.
- Native archives include the compiler, its MIT license, the pinned decision-runtime and gooo-jev license texts, and a NOTICE naming their source revisions and file digests. The [payload guide](../language/release-payload-origins.md) explains the independent archive checks.
- `gooo version --build --json` exposes the eight pure-body maxima, so agents can inspect bounds before preparing source. The [0.6.36 guide](0.6.36-dev.md) explains their scope.

Omitting a model retains deterministic candidate ordering. This release does not change historical model-training measurements.

## What was checked

The [exact-source readiness run](https://github.com/kimjooyoon/meta-ontology-go/actions/runs/39476510503) returned `EVIDENCE_CLOSED` for source `32ac610`. It built each native archive twice and checked matching bytes. The named-input and collection-map journeys were executed and replayed on each platform with finite authored inputs and separate expected-output counts. The [publication run](https://github.com/kimjooyoon/meta-ontology-go/actions/runs/39513610410) completed its release and final receipt jobs. The published Darwin arm64 archive's digest matched `SHA256SUMS`, and its binary reported Go 1.27.3 and the expected clean source identity.

These are bounded examples and packaging checks. They do not establish general program completeness or behavior on every platform configuration.

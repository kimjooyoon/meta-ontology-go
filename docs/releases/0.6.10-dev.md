# Gooo 0.6.10 development guide

This version makes text primitives available consistently in package execution.
`len` and `int64` already worked in body generation; package call resolution now
preserves those primitives, including nested Gooo helper calls and declared
field alternatives. Source activities and local values with the same name keep
their ordinary scope meaning.

The [release page](https://github.com/kimjooyoon/meta-ontology-go/releases) identifies
published files and their exact source. Native execution uses Go 1.27.1 and the
decision runtime remains v0.2.26-experimental. This guide describes the source
candidate; a successful build alone does not establish published release assets.

## Use a text package with actual inputs

The [filename example](../../examples/text-operations/README.md) declares Gooo
prefix, suffix, suffix-removal and byte-length helpers. Its five selection
examples choose the field expressions. A separate input-only request can then
supply filenames without inventing expected answers:

```sh
gooo package execute --json --inputs examples/text-operations/inputs.json \
  examples/text-operations/gooo.workspace.json > out/text-package.json
gooo package replay --json --receipt out/text-package.json \
  --inputs examples/text-operations/inputs.json \
  examples/text-operations/gooo.workspace.json
```

Create `out` first. Results keep actual output values. Input-only requests use
`OBSERVED` and no finite correctness score; selection examples are measured
separately. Saved replay makes zero new predictions. Text lengths and slice
positions count UTF-8 bytes.

## Build a tool that edits Gooo

The public [ecosystem workbench](https://github.com/kimjooyoon/gooo-ecosystem-workbench/tree/8ed738d15e2d60bee21ee1d6d6ed29041989df61)
contains a source-splice tool written in Gooo. It checks the original context,
conditionally replaces a fragment and counts the resulting bytes. Later fields
read earlier decisions and updated values. Go connects files and executes the
generated program.

From that repository, use a compiler containing this version's package fix:

```sh
go run ./cmd/workbench splice --compiler /path/to/gooo \
  --input examples/source-splice/request.json --out out/splice
```

The existing independent graph QAT model can rank the same declared choices by
adding `--model models/graph-chooser-20261008/all-data-demonstration/qat_ternary/model.json`.
Without that option, candidate order is deterministic. Each Text value is
bounded to 1,024 UTF-8 bytes. Results go to a new directory for inspection.

In the [frozen new-program study](https://github.com/kimjooyoon/gooo-ecosystem-workbench/blob/8ed738d15e2d60bee21ee1d6d6ed29041989df61/publication/dependent-splice-20261008/README.md),
the unchanged model completed construction after four candidates and fixed order
after eight. Both complete programs passed 542 separate input tuples and saved
replay. The model's first choice failed; at two attempts it matched fewer fields
than fixed order. These are observations of one new program with fixed wording
and choices, not an estimate of arbitrary intent completion.

Both tool variants changed a Gooo function from `input + 1` to `input * 2` and
compiled the returned source. Independent inputs -5, 0 and 9 returned -10, 0 and
18. This is a small working step toward using Gooo tools to construct other Gooo
programs. Broader program synthesis and conditional/joint model choices remain
research work.

## Release observations

Each readiness platform retains division (8 inputs), retry (12), filenames (12),
their saved executions and the source-only model graph export. This version
also runs the filename workspace on three actual inputs and replays the saved
package. Its validator checks the output fields, zero runtime predictions and
unchanged generated code, while keeping the input-only score unobserved.
These checks are separate from the 26 structural release cases.

The independent graph-model weights remain in the workbench repository. This
compiler version adds no training, model download, or runtime inference to a
saved program.

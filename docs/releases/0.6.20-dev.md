# Gooo 0.6.20 development guide

An activity can now carry an explicit URI ID. Its source name can change from
`Total` to `합계` while the package interface, generated function markers and
native delivery traces retain `urn:gooo:example:total`.

The name is a label on a part; the ID records which part it is. Keeping both lets
an API change tool describe a rename and follow the same declaration. Source
references still use names, so bindings, entry names and input keys need updating
when those names change. New source contents require fresh execution receipts.

The [release page](https://github.com/kimjooyoon/meta-ontology-go/releases) records
publication and exact sources. `gooo version --build --json` identifies the
installed binary. This candidate uses Go 1.27.2 and optional decision runtime
v0.2.26-experimental.

## Compute with a stable identity

From the compiler checkout, build the CLI and run the public example:

```sh
go build -trimpath -o .gooo ./cmd/gooo
./.gooo body-compose \
  --source examples/stable-activity-identity/english/source.gooo.fixture \
  --cases examples/stable-activity-identity/english/cases.json \
  --entry Total --out out/stable-english
```

Its full activity body is Gooo source:

```gooo
activity Total(Integer, Integer) -> Integer id "URN:gooo:example:total" computes `let result = input0 + input1
if result < 0 { result = 0 }
return result`
```

The compiler checks the two integer inputs and generates a native function with
the canonical URI. The four supplied cases cover a positive sum, a negative sum
clamped to zero, zero, and `9007199254740993 + 7 = 9007199254741000`. Native values
retain their exact integer representation within the signed 64-bit range.

Constructing runs the generated program twice. Replay uses the saved composition
and rebuilds it without a new model call:

```sh
./.gooo body-compose --source out/stable-english/original.gooo \
  --cases examples/stable-activity-identity/english/cases.json \
  --composition out/stable-english/composition.json
```

Inspect `composition.plan.activities[].id`, the generated markers in
`composition.source`, and `runtime.traces[].deliveries[].activity_id`. All refer
to the canonical `urn:gooo:example:total`. `finite_passed` and `finite_total`
describe the four supplied expectations.

## Rename the activity to Korean

```sh
./.gooo body-compose \
  --source examples/stable-activity-identity/korean/source.gooo.fixture \
  --cases examples/stable-activity-identity/korean/cases.json \
  --entry 합계 --out out/stable-korean
./.gooo package interface --json \
  examples/stable-activity-identity/english/gooo.workspace.json
./.gooo package interface --json \
  examples/stable-activity-identity/korean/gooo.workspace.json
```

The Korean example declares the same URI with a lowercase scheme. URI parsing
canonicalizes the scheme, so both examples identify the same activity. They
generate the same native program and use separate source-bound receipts. A
duplicate canonical ID within one package is rejected, including differently
cased spellings of its URI scheme.

The release's existing native profile runs both examples and their saved replay
on Linux, Windows and the two macOS architectures. It checks the plan, generated
markers, ordered input ports, exact native values and delivery IDs. Changed IDs,
missing traces, rounded integers and failed deliveries cause the profile to fail.

## Let Gooo and the own small model describe the change

In an [ecosystem workbench](https://github.com/kimjooyoon/gooo-ecosystem-workbench)
checkout, use absolute paths to this compiler and its two example manifests:

```sh
go run ./cmd/workbench api-diff --compiler /absolute/path/to/gooo \
  --before /absolute/path/to/compiler/examples/stable-activity-identity/english/gooo.workspace.json \
  --after /absolute/path/to/compiler/examples/stable-activity-identity/korean/gooo.workspace.json \
  --out out/stable-api-change
```

The join follows the canonical ID. Gooo's `recipes/api-changes.gooo` can classify
the entry wiring and declaration-name changes while the function's input and
output types remain the same. Add `--model` with a compatible graph chooser to
let the existing own small model order source-declared assembly choices. Omitting
the model selects deterministically. Saved execution makes zero new model calls.

The report keeps authored selection cases, actual changes and supplied correctness
labels in separate counts. For a run with no labels on its actual changes,
`named_total` is zero. A source name is visible to callers; an unchanged ID alone
does not establish compatibility for those callers or for changed body behavior.
Observing execution gives another piece of evidence.

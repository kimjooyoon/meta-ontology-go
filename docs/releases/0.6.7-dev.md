# Gooo 0.6.7 development guide

This development version brings source-controlled refinement and continuation
into the CLI. The [release page](https://github.com/kimjooyoon/meta-ontology-go/releases)
lists published binaries and their exact source identities. Native program
execution also needs Go 1.27.1 on the host.

## What changed since 0.6.6

- Continue saved record-choice helpers before their callers. Recheck affected
  candidate scores with the updated helper body and preserve historical sources.
- Use `gooo package resume` with a Gooo policy to continue supported saved package
  constructions, within the declared choices and cumulative limits.
- Run `body-refine --search-policy` so a Gooo policy can incorporate failed direct
  inputs, revise an attempt bound or select the next source-declared search setting.
- Declare quadratic/v1 or quadratic/v2 integer-hole search. Three-point body
  observations propose integer roots and input-dependent expressions. Version 2
  prioritizes shared fits while retaining the version 1 candidate universe.
- Read declared attempt budgets and candidate-space counts from source-bound
  construction records. Functional test results and search coverage remain separate.

The original Gooo body, intent, permitted alternatives and expectations control
these operations. The compact model can rank record choices. Deterministic
construction remains available and saved execution calls no new model.

## Try source-owned numeric refinement

Run from this compiler repository after building or installing this version:

```sh
gooo version --build --json
gooo body-refine --source examples/quadratic-fit-feedback/source.gooo.fixture \
  --activity Build --feedback-cases examples/quadratic-fit-feedback/feedback-cases.json \
  --evaluation-cases examples/quadratic-fit-feedback/evaluation-cases.json \
  --policy examples/search-feedback/policy.gooo.fixture --search-policy \
  --max-attempts 8 --max-rounds 4 --out out/quadratic-fit-feedback
```

The source declares an initial grammar and one later alternative. The Gooo policy
chooses when to advance. The earlier pinned experiment moved from 1/10 to 10/10
feedback matches and passed three separate evaluations. It retained 16 of 108
candidates, so its grammar receipt still reports truncation. See the
[full source and observation](../research/quadratic-fit-feedback-20261008/README.md).

The selected factor can have either sign when only its square is observed.
Expectations for an exposed signed value must state that extra requirement.
Three-point fits are proposals; branches, higher-degree expressions and integer
overflow still need full-body scoring. Unresolved cases stay visible.

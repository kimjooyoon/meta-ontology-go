## Source declarations used by Go

The compiler can [generate an importable Go library](../language/package-library-generation.md)
from authored Gooo bodies. Gooo owns the records, conditions and calls; the host
passes typed values to the generated functions. Selected stages can be exported
by stable activity ID while source names provide a readable Go naming view.

The compiler now uses this route for its own version. The nine-line
[`version.gooo`](../../internal/meta/releaseidentity/version.gooo) declares
`release://activity/current-version`, and its generated `Evaluate()` supplies
the CLI's version. The publication workflow derives its version and tag from
that value. Independent expected-output checks retain their own expectation.
The [publication contract](../external/gooo-release-publication-v4.md) describes
the version source and the generated projection.

For a small example, save that source and a workspace manifest containing:

```json
{
  "schema": "gooo/package-workspace-manifest/v1",
  "entry": {"package_path": "releaseidentity", "activity": "CurrentVersion"},
  "packages": [{"path": "releaseidentity", "sources": ["version.gooo"]}]
}
```

Then generate the library:

```sh
gooo package generate --go-package versionlibrary --out ./versionlibrary gooo.workspace.json
```

An importing Go program can call `versionlibrary.Evaluate()` with no arguments;
this source returns `"0.6.39-dev"`. Generation records its source and compiler
identity. The caller retains the generated file with the original workspace.

## Caller-owned sessions and stable record references

[Workspace sessions](../language/workspace-sessions.md) let an agent execute,
inspect the receipt, then request saved replay within one bounded owner.
Every request reconstructs its current source and inputs and performs two fresh
native runs. The owner retains at most one verified executable and supports
cancellation and explicit close. Historical artifact build information stays
separate from the current build and runs.

The ports [captured-assessment example](https://github.com/kimjooyoon/gooo-go-ports/pull/264)
uses a separate compiler276 profile. The actual ports native verifier's session
adapter remains tracked by [#1855](https://github.com/kimjooyoon/meta-ontology-go/issues/1855).
Its existing compiler205/native17 defaults and full case population retain
their own qualification requirements.

[Record references](../language/domain-record-identity.ko.md) preserve declared
type identity across display renames, including references inside authored
bodies and generated Go types. Original field IDs and declaration ownership
remain available when an agent joins generated records with source interfaces.

## Observed checks and first use

The original [push readiness run](https://github.com/kimjooyoon/meta-ontology-go/actions/runs/41049546864)
checked the exact source on Darwin arm64, Darwin amd64, Linux amd64 and Windows
amd64. Its aggregate retained 26/26 authored release cases and 39 metric
bindings. The original [publication run](https://github.com/kimjooyoon/meta-ontology-go/actions/runs/41050508806)
published nine assets with eight checksum entries and an annotated tag pointing
to the source above. The previous 0.6.38 tag retained its original target.

On the maintainer's existing Go 1.27.3/macOS arm64 environment, the actual public
archive was downloaded and rehashed. Its binary reported the exact clean source,
generated the version library above, and an importing Go program returned the
authored value. A fresh diagnostic project also matched its eight execution
expectations; saved replay on new inputs returned the three outputs in the
first-program guide. Those are separate finite observations. Both routes used
zero model calls. The standard `go list -m -json` query resolved the release tag
to the same source without downloading a source archive.

The [digest table](../getting-started.md#read-a-digest-with-its-full-field-path)
distinguishes raw file checksums from the report's typed-JSON digest. A private
reader initially confused those representations; the original rejection was
retained and the reader was corrected using the existing Go report validator.
Published bytes and replay authority stayed unchanged. Source and field names
identify what was checked; adoption, performance and model learning keep their
own populations and observations.

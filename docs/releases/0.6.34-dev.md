## Choosing a model

[V3 source/model guide](../source-relative-v3-contract-model.md) links the pinned
sources, actual paired Go fits and both public model files. In the new evaluation
cohort, first complete candidates were V2 21/64 and V3 18/64; bilingual first-mask
agreement was11/32 and5/32, respectively. V3 is an explicit experimental option.
The default model and deterministic omission retain their existing behavior.

The model ranks source-owned comparison and branch choices. Gooo preserves
assignments, arithmetic and every declared output/Boolean requirement. It checks
the proposed body and continues through its finite palette as needed. Subsequent
steps do not call the model again.

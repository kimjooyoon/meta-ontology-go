# Gooo 0.6.8 development guide

This version lets a source prepare local values before choosing which ones to
connect to its result, and adds signed integer division and remainder. Check the
[release page](https://github.com/kimjooyoon/meta-ontology-go/releases) for published
assets and their exact source. Native execution also requires Go 1.27.1.

## Prepare values before assembling the result

An assembly candidate may leave a local unread. Its initialization and later
assignments still execute in their original order and scope. The compiler adds
a Go-only no-op read when needed, while Gooo source and candidate selectors keep
their original structure. An executed initializer can still return an evaluation
error; unentered branches stay unevaluated.

The [retry example](../../examples/candidate-locals/README.md) computes a decision,
a capped delay and a reason, then allows three field choices to connect those
values to the output. From the compiler repository:

```sh
gooo version --build --json
gooo body-compose --source examples/candidate-locals/retry.gooo.fixture \
  --cases examples/candidate-locals/cases.json --out out/retry-068
gooo body-compose --source examples/candidate-locals/retry.gooo.fixture \
  --cases examples/candidate-locals/cases.json \
  --composition out/retry-068/composition.json
```

The output directory must be new for construction. Add a compatible local
`--model /path/to/shared-qat/model.json` to rank the three binary choices; omit it
for deterministic ordering. Saved replay makes zero new model calls. This
release uses public decision-runtime v0.2.25-experimental and existing weights.

The [earlier source-pinned observation](https://github.com/kimjooyoon/meta-ontology-go/wiki/Candidate-Locals)
records five construction cases, fifteen fields and twelve separate native cases
all matching. The model-guided run tried one candidate, while fixed order tried
eight. These measurements describe the recorded example and compiler revision.

## Integer quotient and remainder

`/` and `%` are available in ordinary typed bodies, declared IR fills and record
choices. They use Go int64 semantics, including truncation toward zero, signed
remainders and the MinInt64/-1 boundary. Constant zero divisors fail type checking;
evaluated variable zero divisors report an error. Short-circuit Boolean and
conditional evaluation keep unentered calculations inactive.

```sh
gooo body-compose --source examples/integer-division/source.gooo.fixture \
  --cases examples/integer-division/cases.json --out out/division-068
```

The [division guide](../../examples/integer-division/README.md) gives the input and
result record. The closed scalar model's operator vocabulary and the existing
search grammars retain their declared operations.

## Reading the evidence

The release platform witness constructs and replays these examples using the
actual candidate binary on its native runner. Division has eight native cases;
retry has twelve. Raw platform observations remain in readiness artifacts.
Those counts are separate from the 26 structural release cases and each source's
construction cases. Finite examples leave other inputs unmeasured.

Older receipts may record an unread local as a type-check failure. That attempt
now has a different outcome, so replay may reject the older history. Preserve the
original compiler for historical replay; create a fresh construction record with
this version. Prior release assets and experiment records remain immutable.

후보가 일부 변수를 쓰지 않아도 조립을 계속할 수 있습니다. 초기화와 분기의 동작은
그대로 유지합니다. 재시도 여부·대기 시간·사유를 만드는 예제로 직접 실행해볼 수 있습니다.

정수 나눗셈과 나머지도 본문에 쓸 수 있습니다. 작은 모델은 허용된 선택지의 순서를
추천하고, 모델을 생략하면 고정 순서로 진행합니다. 맞힌 사례와 확인하지 않은 범위를
따로 기록하며, 저장한 결과는 새 추론 없이 다시 실행합니다.

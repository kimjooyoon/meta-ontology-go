## Try a branch without a model

`Choose` has two legal layouts, both matching its local `0 -> 0` example.
The caller supplies `3 -> 6`, which distinguishes them. Gooo tests the first
locally selected layout, then the other within two program attempts.

```sh
gooo body-construct --source examples/caller-typed-paths/unary.gooo.fixture \
  --entry Main --construction-cases examples/caller-typed-paths/construction-cases.json \
  --cases examples/caller-typed-paths/evaluation-cases.json --attempts 2 \
  --out out/typed-unary

gooo body-construct --source out/typed-unary/original.gooo \
  --construction out/typed-unary/construction.json \
  --cases examples/caller-typed-paths/evaluation-cases.json
```

The second command reuses the selected program and its construction history,
with zero new inference. The unary spelling `-input`, negated locals and nested
integer negation normalize to the bounded `0 - expression` arena. Source IDs,
local obligations, caller feedback and subsequent evaluation remain distinct.

## Combine a record and a typed branch

```sh
gooo body-construct --source examples/caller-typed-paths/mixed-model.gooo.fixture \
  --entry Main --construction-cases examples/caller-typed-paths/mixed-construction-cases.json \
  --cases examples/caller-typed-paths/mixed-evaluation-cases.json \
  --model examples/scalar-identity/model/model.json --attempts 16 \
  --out out/typed-mixed

gooo body-construct --source out/typed-mixed/original.gooo \
  --construction out/typed-mixed/construction.json \
  --cases examples/caller-typed-paths/mixed-evaluation-cases.json
```

## Installation after publication

verify SHA256SUMS before installing. The expected names remain
`gooo-darwin-arm64.tar.gz`, `gooo-darwin-amd64.tar.gz`,
`gooo-linux-amd64.tar.gz` and `gooo-windows-amd64.zip`.
Use `gooo version --build --json` to read exact binary/toolchain/source identity.
Public URLs, checksums, installation observations and accepted source will be
added after the original publication succeeds.

These observations cover finite source behavior and their recorded inputs.

measurements.

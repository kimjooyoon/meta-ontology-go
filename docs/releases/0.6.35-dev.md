## Read a saved result with Gooo

From the diagnostic project containing `execution.json`, fetch two small source
files from this release's exact source. The Gooo program owns the generation/use
relations; the compiler transports retained rows.

```sh
mkdir rdf-origin
GOOO_SOURCE=de99b770b8b5adea608233c3c0664902336e3310
curl --fail --location "https://raw.githubusercontent.com/kimjooyoon/meta-ontology-go/$GOOO_SOURCE/examples/recorded-use-origins/inspect.gooo" -o rdf-origin/inspect.gooo
curl --fail --location "https://raw.githubusercontent.com/kimjooyoon/meta-ontology-go/$GOOO_SOURCE/examples/recorded-use-origins/rdf.workspace.json" -o rdf-origin/workspace.json
gooo package execute --json --origin-receipt execution.json \
  --origin-shape local-use-columns --origin-offset 0 rdf-origin/workspace.json
```

The first retained use in this starter yields `RDF_READY`. Other documents retain
their own missing-record, page and source-mapping statuses. Model training,
external adoption and language completeness have their own evaluation scopes.

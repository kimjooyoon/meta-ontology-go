# 설명 표현의 영향을 줄이는 작은 결정 모델

이 개발 경로는 SDK0.2.45의 명시적 prose-neutral 모델을 `.gooo` 소스 조회와
본문 조립에 연결합니다. 조건과 반환값 예시가 이미 목표를 표현하는 경우,
설명의 말투가 바뀌어도 같은 구조화된 정보를 판단에 사용할 수 있습니다.

모델 입력528개 값 중 설명문에 해당하는128개 값만 지웁니다. 나머지400개
소스 값과 모든 출력·Boolean 사례는 유지합니다. 원본 설명은 소스와 기록에
남습니다. 모델 파일 형식은 이 입력 정책을 별도로 식별합니다.

작은 신청서의 설명 칸은 기록하고, 계산에 필요한 예시와 스위치 위치는
판단기에 전달하는 식입니다. 판단기는 먼저 검사할 조합을 제안합니다.
실제 계산과 충족 여부는 원본 소스의 유한 후보 검사로 확인합니다.

## 사용

[공개 모델 파일과 SDK 연결 정보](https://huggingface.co/asketeddy/gooo-canonical-decision-tiny-v1/tree/7bbc2fd0920696749979e545325d7ebbd05ebd8a/profiles/source-relative-v3-prose-neutral-20261012)를
사용합니다. 모델 SHA256은
`8ef9d0f6a580f95e115ad740763d00c0bdbbb37912d26c2beed75ce8868bc6c5`입니다.
기존 학습 가중치와 텐서 값이 같고, 입력 정책을 담은 새 파일로 포장했습니다.

공개 Gooo0.6.34는 일반 V3 모델을 읽습니다. 이 새 파일 형식은 아래 개발
소스에서 사용하며, 컴파일러 배포는 별도 검사를 거쳐 진행합니다.

```sh
GOWORK=off GOTOOLCHAIN=go1.27.2 go run ./cmd/gooo body-context \
  --activity Charge --model explicit-neutral-model.json source.gooo

GOWORK=off GOTOOLCHAIN=go1.27.2 go run ./cmd/gooo body-codegen \
  --json --activity Charge --path-model explicit-neutral-model.json source.gooo
```

조회는 모델 판단·후보 실행0회이며, 입력 정책과 제외한 범위, 원본 설명,
출력·조건 사례와 실제 입력 해시를 보여 줍니다. 조립은 후보 실행 전에 한 번
판단한 뒤 남은 유한 조합을 이어서 검사합니다. 이후 단계의 새 판단은0회입니다.
모델을 생략하면 결정론적으로 진행합니다. 지원되지 않는 소스 형태는 이유와
결정론적 경로를 유지합니다. 일반 V2·V3 파일은 기존 해석을 유지합니다.

가중치는19,034개 FP32 값으로76,136바이트입니다. 입력과 작업 공간은 고정
배열을 사용하며, 이 숫자는 프로세스 전체 메모리 사용량과 구분합니다.

## 어떤 결과를 근거로 추가했나

[공개된 요인별 실험](https://huggingface.co/asketeddy/gooo-canonical-decision-tiny-v1/tree/0aa1dd8c51e730632f0f4bc590b5498799178492/research/factorized-decision-20261012/result)에서
설명을 제외한 모델은 첫 본문264/512, 유한 검사 후512/512를 충족했습니다.
평가512문서는16목표 계약·4연산 조합을 표현과 배치로 반복한 것입니다.
248개 첫 본문은 출력 사례 일부를 틀렸습니다. 반환 가지와 소스 배치에 따른
판단은 더 개선해야 합니다.

한영 설명을 바꾼 쌍은 같은 입력 배열이 되어 같은 판단을 냅니다. 이 일치는
입력 구성에서 따라오는 결과입니다. 자연어 이해율이나 전체 프로그램의
정확도를 이 수치로 주장하지 않습니다. 기존 학습·평가 결과는 보존하고,
새 형식으로 포장하는 작업은 가중치를 바꾸거나 다시 예측하지 않습니다.

새 단가 계산 예제의 회귀 검사는 합성 영점 가중치로 입력128개 제외/400개
보존, 전체 사례 유지, 실제 판단 입력 해시, 최초 판단1회, 유한 조립 완료,
모델 생략과 명시적 입력 형식 불일치를 확인합니다. 학습 모델을 쓰는 과금
예제는 소스·사례를 실행 전에 별도로 공개하고 첫 선택과 검사 후 결과를
각각 기록합니다. 학습 모델의 native 결과와 속도는 이 회귀 검사의 범위 밖입니다.

[새 과금 예제의 실행 전 계획](https://huggingface.co/asketeddy/gooo-canonical-decision-tiny-v1/tree/168d281af8594b3f32e56dc3c34cac6ca74b881e/research/neutral-usageband-dogfood-20261012/prefit)은
4093 기준·단가7/5의 한 계약을 선언합니다. 별도 평가8입력 중 경계3개는
선언 사례와 겹칩니다. 결과를 보며 모델이나 사례를 바꾸지 않고 최초 결과를
보존하며, 이 한 예제로 일반적인 정확도를 주장하지 않습니다.

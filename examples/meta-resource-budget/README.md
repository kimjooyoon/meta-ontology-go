# Meta resource budget experiment

This is a small, read-only experiment over the two real `.gooo` sources in
this directory. CI measures three meta operations three times each:

| operation | stage / step | output |
| --- | --- | --- |
| `observe-source-receipt` | `LOWER / parse-source` | receipt bytes |
| `project-generated-operation` | `PROJECT / project-operation-manifest` | generated bytes |
| `prove-generated-replay` | `REPLAY / replay-generated-artifact` | generated bytes |

Every sample records wall time, peak RSS, receipt bytes, generated bytes,
producer, consumer, meta-operation, proof choice, stage, step, and reason.
The fixed denominator is 22 coordinates: 16 operation/resource coordinates
and 6 source, semantic, effect, and sample-set coordinates.

Resource observations are runner-scoped and non-deterministic. The reducer
therefore treats them as evidence about one exact CI environment, while the
source receipt and byte-identical artifact replay are deterministic semantic
evidence. A complete over-budget sample is an exact, known refutation of the
resource claim only; it does not refute the semantic artifact. A missing
sample lowers the resource resolution to `LOWER_RESOLUTION` and leaves the
resource claim `OPEN`; it does not erase the exact semantic verdict.

The normal, over-budget, and missing-sample cases are generated in CI and
reduced by `cmd/meta-resource-budget-reducer`. The reducer is a separate
consumer from the shell producer. Its append-only claim transitions retain
`OPEN -> DISCHARGED`, `OPEN -> REFUTED`, or `OPEN -> OPEN` with stage, step,
reason, evidence digest, and a chained digest.

The budget is intentionally a useful envelope, not a host guarantee:

| resource | limit |
| --- | ---: |
| wall time | 2,000 ms |
| peak RSS | 131,072 KiB |
| receipt bytes | 8,192 bytes |
| generated bytes | 16,384 bytes |

The GitHub-hosted runner reference describes the VM/container and available
hardware, while Bazel's hermeticity guidance explains why fixed inputs and
declared tools matter for reproducibility. This experiment adopts their
separation of environment from input identity, but does not claim hermeticity:
it uses a hosted runner, `/usr/bin/time`, the runner kernel, and a mutable
`ubuntu-latest` image. It also does not claim cross-run performance,
machine-independent bounds, business correctness, production readiness, or
repository mutation authority.

# Domain investment plan example

This example shows how a `.gooo` system can turn capability discovery observations into an explicit investment question without treating domain completeness as a truth score.

The scope is declared first, observed capabilities and unresolved boundaries are counted from evidence, and a target ratio is supplied as policy. The resulting disposition is one of `UNKNOWN`, `DEFERRED`, `INVESTIGATE`, `INVEST`, or `MAINTAIN`.

`INVEST` means only that observed coverage is below the supplied target. `MAINTAIN` means only that the supplied target is met. Neither result authorizes execution, expands scope, or proves semantic correctness.

# Self-Improvement Contract

This Gooo package declares the language's closed self-improvement loop.

The loop measures a source tree, chooses an explicit Munchhausen proof route,
builds a generation plan, executes registered metaprograms, evaluates their
receipts, verifies evidence, and returns an improved source tree.

Executor entities use stable identifiers derived from the live generation
registry. The contract compiler rejects missing executors, broken activity
edges, incomplete proof choices, invalid semantic lowering, and
non-deterministic replay.

The declaration does not authorize promotion. GitHub Actions remains the
external conformance authority.

The language experiment enters through `Observe` as a
`ReadOnlyImprovementInput`. No other activity consumes that value yet. This
keeps candidate generation, execution, mutation, and automatic adoption at
zero while making the next extension point explicit in Gooo rather than only
in a metric report.

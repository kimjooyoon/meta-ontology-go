# Diagnostic provenance use cases

The fixed `corpus.json` denominator is 18 cases at version `2026-08-23`.
CI loads this file and compares it with the metaprogram registry before
executing any case.

## Generated diagnostic

A formatter diagnostic inside exactly one generated range is traced from the
generated byte to the source-map semantic ID and then projected to a source
LSP range. Entity, field, activity, and slot mappings must pass `4/4`.

## Line-directed Go diagnostic

The same Go token retains both `PositionFor(pos, false)` physical coordinates
and `PositionFor(pos, true)` logical coordinates. The corpus requires exactly
one observed remap and never replaces one coordinate with the other.

## Unknown or ambiguous provenance

Unknown origin, stage, severity, code, coordinates, and absent or ambiguous
source maps are not assigned a guessed semantic ID. All eight boundaries must
return their registered rejection code, which lowers the report to
`FAIL_CLOSED / LOWER_RESOLUTION` if any boundary is accepted.

# Self-improvement observation

This example is a bounded, read-only compiler observation loop. The
`observation.gooo` authority declares the observed semantic activity, its
canonical normalized-IR identity, its allowed read effects, and the exact
duplicate-input candidate rule.

`gooo observe` runs the real `generate` lowering path twice on `input.fixture`.
It records the phase, operation ID, canonical input digest, and source span
for each evaluation. A candidate is emitted only when the same pure operation
is evaluated more than once for the same digest. Safety and benefit are left
unknown; no repository change is adopted.

The fifth iteration continues with `gooo propose`, which writes a
proposal-only artifact from that candidate. `gooo adopt` requires a separate
`explicit-human-input` authorization artifact before it exercises the real
semantic generator. With authorization, the bounded compiler reuse seam runs
the same input twice, reuses the exact normalized-IR result on the second
evaluation, and writes only a caller-owned adoption result. Without that
authorization, the result is `UNKNOWN` and the compiler is not executed.

The CI loop binds the authorized result into the existing six-artifact
semantic operation envelope for NORMAL, UNKNOWN, REFUTED, and REPLAY cases,
then independently re-verifies the candidate, authorization, exact 2 -> 1
operation-count pair, generated bytes, normalized semantic digest, and the
no-repository-write boundary.

# Self-improvement observation

This example is a bounded, read-only compiler observation loop. The
`observation.gooo` authority declares the observed semantic activity, its
canonical normalized-IR identity, its allowed read effects, and the exact
duplicate-input candidate rule.

`gooo observe` runs the real `generate` lowering path twice on `input.fixture`.
It records the phase, operation ID, canonical input digest, and source span
for each evaluation. A candidate is emitted only when the same pure operation
is evaluated more than once for the same digest. Safety and benefit are left
unknown; no repository change is adopted.

The fifth iteration continues with `gooo propose`, which writes a
proposal-only artifact from that candidate. `gooo adopt` requires a separate
`explicit-human-input` authorization artifact before it exercises the real
semantic generator. With authorization, the bounded compiler reuse seam runs
the same input twice, reuses the exact normalized-IR result on the second
evaluation, and writes only a caller-owned adoption result. Without that
authorization, the result is `UNKNOWN` and the compiler is not executed.

The `.gooo` authority also declares that any retained result is an immutable,
caller-owned certificate: it must be verified before consumption, missing
evidence is `UNKNOWN`, and stale or mismatched evidence is `REFUTED`.

The sixth iteration closes the next boundary with two separate compiler
invocations. `gooo certify` re-runs the authorized real lowering path and
writes `retained-knowledge-certificate.json` plus `retention-before.json`.
A later `gooo consume` process verifies the exact contract, proposal,
authorization, source, normalized IR, compiler, toolchain, policy, and
verifier digests before consuming the stored generated bytes. The hit reports
zero semantic operations and one certificate hit; the independent verifier
compares it with the first invocation's bytes and normalized semantic digest.

The retained-knowledge loop has a fixed six-case denominator: certificate hit
and replay are `CLOSED`; missing certificate and missing authorization are
causal `UNKNOWN`; stale input and a mismatched certificate are causal
`REFUTED`. Each case is bound into six independently checked envelope
artifacts, exactly 36 total. Wall time and peak RSS are reported as measured
integers, but no performance superiority claim is made when those process
measurements are not comparable. No repository source is rewritten and no
local tests are executed.

The seventh iteration promotes that certificate into the ordinary compiler
path. After the evidence is certified, a caller can run one normal generation
command with `--certificate`, `--contract`, `--observation`, `--proposal`,
`--authorization`, and `--adoption`. The command verifies the `.gooo`
`PublishOperationReceipt` policy and every source, semantic, compiler,
toolchain, verifier, proposal, authorization, policy, and certificate digest
before writing the exact retained `semantic.gooo.go` bytes. It also writes a
JSON report and a human-readable `generation-report.md`; missing, stale,
mismatched, or unauthorized evidence writes report-only `UNKNOWN` or
`REFUTED` output and never falls back to baseline generation.

The ordinary command without those explicit certificate flags remains the
baseline compiler path. A caller that wants a measured baseline report may
add `--retention-report`; the report records the operation count, certificate
hit/miss counts, output file count and bytes, wall time, and peak RSS without
claiming superiority from noisy process measurements.

# Capability-scoped expansion

`main.gooo` is the one semantic source used for every case. Its `computes`
value programs define policy, capability kind/operation/target, prior claim
state, evidence class, and nine cases. Activity names and comments are not
authority.

The CI provider actually reads one pinned file from a temporary sandbox and
one deterministic logical input. Environment and network are not contacted, so
they are `UNKNOWN` or `HISTORICAL_FIXTURE`, not current evidence. The separate
provider command sends three write/mutation/promotion token requests to a
default-deny broker and records three denials. Repository and sandbox
before/after snapshots are separate evidence scopes; OS authority is
`NOT_OBSERVED`.

The independent consumer parses and lowers the raw source again, consumes raw
provider observations, directly reobserves the pinned file and logical input,
reparses the one ALLOW expansion artifact, and does not import the producer.
CI also runs policy, comment-only, graph-edge-removal, and forged-provider
interventions. This is a bounded experiment, not a general macro sandbox.

# 입력 없이 정해진 결과를 만드는 활동

빈 작업 계획은 여러 곳에서 같은 모양으로 필요하다. 이 예제는 `EmptyPlan()`에
그 값을 한 번 적고, `Prepare`에서 필요할 때 호출한다. 에이전트가 같은 레코드를
여러 분기에 복사하지 않고 활동 이름과 원본 위치를 따라 읽을 수 있다.

```gooo
activity EmptyPlan() -> Plan computes `
    return Plan{state: "NO_WORK", tasks: []string{}}
`
```

## 실행

이 예제는 인자가 없는 순수 활동 호출을 지원하는 개발 컴파일러가 필요하다.
현재 `0.6.36` 릴리스 준비 소스에는 이 후속 변경이 포함되어 있지 않다.

```sh
gooo package execute --json --cases cases.json gooo.workspace.json > execution.json
```

입력 문자열이 비어 있으면 빈 계획을, 값이 있으면 작업 하나를 담은 계획을 반환한다.
두 사례는 이 작은 프로그램의 기대값이다. 새 모델이나 고객 CI 설정은 필요 없다.

## 입력과 출처의 의미

`EmptyPlan()`은 호출자의 `input`이나 지역 변수를 가져오지 않는다. 선언된 본문만
실행하고 반환 값도 다른 호출의 결과와 공유하지 않는다. 필요한 값이 있으면
활동의 입력에 선언해 전달한다. 인자가 없어도 호출 횟수·재귀·깊이 제한은 그대로
적용되며, 활동 ID와 본문 변경은 출처와 재실행 비교에 들어간다.

현재 추가한 범위는 본문에서 부르는 고정 `computes` 활동이다. 외부 입력으로
시작하는 실행 진입점은 기존 입력 계약을 사용한다. 이 예제의 진입점은 Text를
받는 `Prepare`이고, `EmptyPlan`을 별도 입력 단계로 만들지 않는다.

# Gooo release publication

`main.gooo` is the semantic authority for the first experimental Gooo release
publication path. Its eight activities are a fixed denominator, not a workflow
description inferred from prose.

The GitHub Actions publication contract binds this source digest to one exact
merge commit, one successful release-readiness run, eight release assets, and a
final publication receipt. Missing or skipped evidence remains UNKNOWN and
cannot create a release.

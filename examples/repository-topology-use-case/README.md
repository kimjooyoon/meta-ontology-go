# Repository topology receipt example

The GitHub Actions artifact contains one exact-head JSON receipt with every
file row and every directory row. The human summary intentionally has three
fixed projections:

| Audience | Fixed denominator | Direct question |
| --- | ---: | --- |
| `READER` | 4 | Are file lines, directory counts, Go totals, and Gooo totals exact? |
| `IMPLEMENTER` | 7 | Are those facts connected to known meta operations and ontologies? |
| `GOVERNOR` | 10 | Is the whole receipt exact-head, explicit about root exceptions, and read-only? |

Counts change with the repository. The denominators do not change without a
schema version change. The receipt reports observations rather than inferring
overall language quality.

# 고른 Gooo 본문을 호출해서 실행하기

[소스](main.gooo.fixture)의 `Main`은 `Fee(input+1)`을 호출한다.
`Fee`는 음수 입력에서 0을 반환하고, 나머지는 두 배로 계산하되 상한은 120인
고정 조건을 가진다. 선택지는 음수 분기와 상한 분기의 배치다.

작은 합성 모델이 네 조합의 시도 순서를 한 번 제안한다. 기존 구성 흐름이
선택 조건을 평가해 mask 1의 본문을 고른다. 호출자와 그 본문을 Go 프로그램으로
내보낸 뒤, 실제 프로그램에 [호출 입력](cases.json)을 전달한다.

| Main 입력 | Fee가 받는 입력 | Main 기대 결과 |
| --- | --- | --- |
| -4 | -3 | 0 |
| 16 | 17 | 34 |
| 100 | 101 | 120 |

## 새 관찰

[기록](observation.json)은 공개 컴파일러 소스와 새 테스트 파일 하나를 생산자로 둔다.

- 구성 단계: 모델 호출 **1회**, 선택 조건 **2/2**, 별도 조건 **3/3**.
- 네이티브 실행: 호출자 기대값 **3/3**, 추가 모델 호출 **0회**.
- 기존 실행기는 한 관찰 안에서 같은 입력 묶음을 두 프로세스로 실행하고 출력이
  일치하는지 확인했다. 분모 3은 입력 묶음의 기대값 수이며 프로세스 수는 2다.
- Go `1.27.2`, 이 PC에서 재구성·빌드·실행 전체 관찰 시간 **731,048,125ns**.

이 시간에는 실행 준비와 빌드가 포함된다. 모델 예측 지연이나 다른 언어와의
속도 비교로 해석하려면 해당 구간을 별도로 측정해야 한다.
가중치는 합성이며 학습은 0회다. 학습 모델의 품질, CPU 사용률, 전체 프로세스
메모리와 큰 프로그램의 지연은 후속 관찰 항목이다.
앞선 소스 예제들을 재실행하지 않았고, 각 관찰의 원래 생산자를 유지한다.

## 개발 소스에서 실행

```sh
go run ./cmd/gooo body-compose \
  --source examples/scalar-source-model-native/main.gooo.fixture \
  --entry Main --cases examples/scalar-source-model-native/cases.json \
  --out out/scalar-source-model-native
```

호환하는 수치 결정 아티팩트를 연결하려면 `--model /path/to/metadata.json`을 추가한다.
출력 디렉터리는 새 경로여야 한다. 모델 가중치는 이 예제에 포함하지 않는다.
위 명령은 개발 소스의 사용 안내이며, 저장한 관찰은 테스트 API 경로로 수행했다.
선택 입력과 호출자 입력의 역할은 [모델 연결 안내](../../docs/scalar-source-model.ko.md)를 참고한다.

# Self-Improvement Language Observation

This metaprogram converts one exact-head language example receipt into a
read-only self-improvement input. It consumes the content-bound experiment
report, the fixed `6/6` counterexample summary, and the compiled Gooo
self-improvement contract.

The output exposes three reader resolutions with fixed denominators: user
`5/5`, tool author `12/12`, and governor `16/16`. Every indicator names the
meta-operation that produced it and selects FOUNDATION, COHERENCE, or
REGRESSION.

An accepted input has candidate count `0`, repository writes `0`, and false
mutation, execution, promotion, and automatic-adoption authority. Unknown
source decisions lower the resolution; explicit failures and invalid evidence
fail closed at exact resolution.

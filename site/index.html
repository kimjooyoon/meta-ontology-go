Describe a small program. Run the generated Go. Keep a record you can inspect and replay.

Typed declarations, explicit construction choices, and finite examples live in .gooo source. An optional local model can rank those choices; the compiler checks and executes the selected program.

Run a diagnostic tool

Install the published version, create two Gooo packages, and run them against supplied examples. Then reuse the saved program on three new inputs. This example needs no model or account.

Requires Go 1.27.2 for native execution. These macOS/Linux commands install Gooo locally for this shell. See the installation guide for PATH setup, platform downloads, and what each command does.

GOBIN="$PWD/.gooo-bin" go install github.com/kimjooyoon/meta-ontology-go/cmd/gooo@v0.6.24-dev
export PATH="$PWD/.gooo-bin:$PATH"
gooo init --template diagnostic my-diagnostic
cd my-diagnostic
gooo package execute --json --cases cases.json gooo.workspace.json > execution.json
gooo package replay --receipt execution.json --inputs inputs.json gooo.workspace.json

The final command prints:

"partial: missing branch result [repair-and-replay]"
"unobserved: Add expected observations. [add-examples]"
"complete: All observed fields matched. [accept]"

Edit inputs.json and replay to try your own counts and diagnostic text. Conditions and choices belong to diagnostics.gooo; app.gooo imports the package and formats its result.

Approval policy simulator

Gooo is experimental. Current pure bodies cover bounded scalar and record programs. General loops, collections, and unrestricted Go-library compatibility are outside this profile. Finite examples measure the supplied cases; they do not prove behavior for all inputs.
